# Polaris 1-Minute Launch Video Plan (`brag-plan.md`)

## 1. Product Overview
- **What is it?** Polaris is an offline-first, desktop AI workspace that organizes cluttered folders, searches files with hybrid BM25 + FAISS vector retrieval, and enables conversational document Q&A—all running 100% locally via Ollama.
- **Who is it for?** Developers, researchers, and privacy-conscious professionals managing gigabytes of local documents and code without cloud telemetry or data leaks.
- **Key Differentiator:** True zero-cloud privacy, safe non-destructive previews with instant undo, real-time download watcher toasts, and deep code-editor jump links for every retrieved citation.
- **Visual Hook:** Moving from a chaotic, cluttered workspace to the pristine Obsidian dark card interface with neon emerald accents.
- **Tone:** `default` (Punchy, confident, clean, high-tech dark mode aesthetic).
- **Format:** Landscape (1920×1080 @ 30 fps), target duration: 60.0 seconds (1,800 frames).

## 2. Storyboard & Scene Breakdown (Total Duration: 60.0s)

### Scene 1: The Problem & The Brand Reveal (0.0s – 8.0s | Frames 0 – 240)
- **Visual:** Cluttered chaotic downloads directory vs. data privacy tension.
  - *"Sensitive files. Private code. Personal documents."*
  - *"Why upload them to third-party cloud servers just to organize and search them?"*
  - Reveal: The glowing Polaris Geometric Star Logo emerges with neon cyan radial aura.
  - Headline: **POLARIS** — *100% Offline AI Desktop Workspace*
- **Audio:** Low bass atmosphere with rising synth chime and punchy electronic drop at 5.0s.

### Scene 2: Smart AI Organization & Safe Dry-Run (8.0s – 22.0s | Frames 240 – 660)
- **Visual:** Polaris Organize Tab in action.
  - Shows folder scanning 148 messy incoming files.
  - Preset strategy applied: *"Sort by file type, then size (Small <1MB, Medium 1-50MB, Large >50MB)"*.
  - Live animated preview table showing destination paths.
  - Interactive table editing: destination path cell edit, copy vs move mode radio.
  - Download Watcher toast pop-up: *"⚡ New file detected: Q4_Invoice.pdf -> Move to Documents/Finance?"*
  - 1-Click Apply with green glow and instant Undo button safety.
- **Audio:** Driving 120 BPM synthwave groove with hi-hats, bassline, and UI click effects.

### Scene 3: Grounded Document Chat & Interactive Citations (22.0s – 38.0s | Frames 660 – 1140)
- **Visual:** Polaris Document Chat card with Messenger-style bubbles.
  - Scope toolbar: `[Scope: All Files] [Top-K: 3] [HyDE: Active] [Re-rank: Active]`.
  - User asks: *"What were our Q3 financial figures and deliverables?"*
  - Real-time streaming assistant response with typewriter effect.
  - Clickable blue citation badge: `📄 [1] financial_report.pdf (Page 2) § Revenue [Line 42]`.
  - Interactive Source Inspection modal dialog pops up showing exact highlighted text snippet.
  - Deep-link button: *"📄 Open at Line 42 in VS Code / Cursor"*.
- **Audio:** Tech sequencer arpeggio with data-stream micro-ticks and citation hit chimes.

### Scene 4: Executive Document Summarizer & Entity Extraction (38.0s – 50.0s | Frames 1140 – 1500)
- **Visual:** Summarize Tab with multi-mode analysis.
  - Contract & technical report ingested.
  - Real-time bullet takeaways, action items, and risk factors.
  - Structured JSON Entity Extraction: vendor names, dollar amounts, deadlines.
  - Core badge: *"100% Local LLM · Zero Cloud API Keys · Ollama Powered"*.
- **Audio:** Uplifting synth harmonics building into melodic climax.

### Scene 5: Outro & Call to Action (50.0s – 60.0s | Frames 1500 – 1800)
- **Visual:** High-impact hero card with Polaris emblem.
  - Stack badges: `Python 3.14` · `PySide6` · `FAISS` · `SQLite FTS5` · `Ollama`.
  - Punchline: *"Sanity for your files. Total privacy for your mind."*
  - Value: *"100% Local. 0 Cloud Telemetry. Zero Subscription Fees."*
  - CTA: *"Open Source on GitHub · Star & Clone: github.com/isnotfred/opensrc-polaris"*
- **Audio:** Full stereo chorus with warm resolving chord fade-out.
