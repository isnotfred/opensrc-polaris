Polaris is an offline-first desktop AI workspace that cleans chaotic download folders, searches documents with hybrid BM25 + FAISS vector retrieval, and chats with local files using on-device Ollama models. Every retrieved answer includes verifiable citation badges that deep-link directly to line numbers in your code editor, complete with a real-time download watcher and safe one-click undo. Zero cloud API keys, zero telemetry, and zero subscription fees.

https://github.com/isnotfred/opensrc-polaris
